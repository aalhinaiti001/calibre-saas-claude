# Calibre SaaS

Scoping, concept and product fundamentals for Calibre by Daftar, the finance role hiring decision method.

## Product fundamentals

[product/](product/README.md) holds the foundation that is true in every delivery form: the normative method, the domain model and its invariants, the guardrails, two finance role packs, the Verdict memo template, a Postgres schema with row level security and a passing smoke test, and the decision records. Start with [product/METHOD.md](product/METHOD.md).

## Concept documents

- [docs/CALIBRE-SAAS-CONCEPT.md](docs/CALIBRE-SAAS-CONCEPT.md): the SaaS concept. Problem statement, core user loop, MVP feature list with cuts and deferrals, recommended stack, build sequence, and kill criteria. Read this before touching a build tool.
- [docs/CALIBRE-ALTERNATIVES.md](docs/CALIBRE-ALTERNATIVES.md): the non software concepts (licensed method kit, certified operator, retainer bundle, search firm channel), ranked, with the recommendation and how it relates to the SaaS decision.
- [docs/Calibre-as-a-Product.docx](docs/Calibre-as-a-Product.docx): both documents combined as a Word file in house style, for offline reading.
