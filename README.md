- [docs/CALIBRE-ALTERNATIVES.md](docs/CALIBRE-ALTERNATIVES.md): the non software concepts (licensed method kit, certified operator, retainer bundle, search firm channel), ranked, with the recommendation and how it relates to the SaaS decision.
- [docs/Calibre-as-a-Product.docx](docs/Calibre-as-a-Product.docx): both documents combined as a Word file in house style, for offline reading.
